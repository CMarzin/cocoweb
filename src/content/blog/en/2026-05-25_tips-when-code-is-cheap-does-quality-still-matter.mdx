<WebLinkSection emoji="🤖" url="https://workmux.raine.dev/" text="Workmux" templateClass="mt-4">
Terminal-first workflow for parallel AI agents.
Turn your terminal into a multi-agent workspace. Every task gets a dedicated git worktree and tmux window, letting agents code conflict-free.
</WebLinkSection>

<WebLinkSection emoji="🐇" url="https://mediabunny.dev/" text="Mediabunny" templateClass="mt-4">
A JavaScript library for reading, writing, and converting video and audio files. Directly in the browser, and faster than anybunny else.
</WebLinkSection>

<WebLinkSection emoji="💧" url="https://github.com/AndrewPrifer/liquid-dom" text="Liquid dom" templateClass="mt-4">
